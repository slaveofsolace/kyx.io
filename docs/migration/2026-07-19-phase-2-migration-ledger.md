## Removal boundary

Phase 2 adds seams without deleting the runnable Offline Practice implementation. Legacy movement, bots, weapons, world rendering, and dormant modules remain outside the new authority path until replacement gates pass. The dev route and renderer diagnostics are compile-time excluded from production; the new protocol defines contracts only and opens no socket or public service.
