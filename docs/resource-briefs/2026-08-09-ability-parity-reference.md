# Ability parity reference brief

## Function

Learn high-level, player-visible timing and feedback principles for directional launch grenades, smoke expansion, frag/sticky/flash consistency, and honest Blink destination previews.

## Boundary

- Reference learning only; no ev.io code, audio, VFX, names, or protected assets may enter the implementation workspace.
- Public visibility is not reuse permission.
- No authenticated acquisition, entitlement, archive download, or external asset import is authorized.
- Any external reference candidate remains `REFERENCE ONLY`.
- Implementation assets must be original source code/Web Audio synthesis or otherwise carry explicit provenance and compatible rights.

## Target and budgets

- Runtime: browser FPS, Windows desktop first, current project toolchain.
- Presentation: restrained modern tactical body/contact/tail; no retro arpeggio, arcade chirp, or siren loop.
- Performance: reuse pooled runtime objects where practical; no unbounded particles, audio oscillators, timers, or repeated-contact loops.
- Accessibility: presentation events must remain semantically available without relying on color or audio alone; flash/reduced-motion behavior remains a human-review item.

## Acceptance evidence

- Canonical URLs and retrieval date for every reference.
- Explicit `OBSERVED` versus `INFERRED` notes.
- Source pointers for clean-room implementation.
- Focused authority/presentation tests, build output, local runtime captures/logs, and explicit Human acceptance nonclaim.

Unknown until source and runtime inspection: exact current device envelope, current event schema, baseline ability availability in Practice, and whether audio output can be captured reliably in this environment.
