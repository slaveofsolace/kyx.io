# V6C character Rev16 visual rejection

Status: **NOT G6**

Rev16 removed the former soft toe islands and produced a reproducible,
structurally valid GLB with a clean exact-current render packet. The resulting
model is still visibly below the accepted target.

The front three-quarter, weapon-contact, pelvis, boot, and run views show
open-claw hands, an oversized clipping torso shell, a skirt-like hip rim,
jagged pelvis transitions, cylindrical gaiters, and unconvincing planted run
contact. These are broad silhouette and deformation problems, not evidence
tolerance issues.

The lane is therefore frozen as failure evidence. It is not promoted to
`public/`, not wired into the runtime, and not treated as human-approved.

Next corrective work must replace the torso shell with articulated,
human-proportioned layers; rebuild both hands around the actual rifle grips;
clean the pelvis/waist topology; taper the boots and gaiters; and author a run
cycle with readable heel/toe contact and body weight transfer before another
G6 review.
