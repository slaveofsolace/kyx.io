# KYX.IO Rev17 Character Candidate Provenance

Status: candidate-only; human visual and project legal review remain required.

The Rev17 body, armor, boots, hands, rifle, armature, sockets, materials, LODs,
and animation clips were procedurally authored for this repository through
`../../scripts/author_export_v6c_character_rev17.py` and preserved in
`kyx-v6c-character-rev17-master.blend`.

No downloaded meshes, third-party character bases, third-party rigs, external
motion-capture clips, marketplace assets, private license packs, or ripped game
content were used by the authoring script. Blender's built-in primitives and
operators are authoring tools, not shipped third-party source assets.

This record documents production provenance only. It does not grant G6,
release eligibility, default promotion, legal approval, or human visual
acceptance.
