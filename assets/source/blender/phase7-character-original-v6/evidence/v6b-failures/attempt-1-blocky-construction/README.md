# V6-B failed attempt 1 — blocky construction regression

Status: **rejected and preserved; not the current V6-B candidate**

The first scripted V6-B construction pass technically created separate garment,
armor, helmet, glove, boot, and rifle objects, but direct renders showed that it
buried the accepted continuous V6-A human anatomy under cylindrical garment
cages, oversized primitive-read armor, slab boots, an egg-shaped helmet, and a
block-built rifle/contact pose. The resulting silhouette repeated the exact
assembled-shape/mannequin failure the user rejected in earlier character work.

The Blend, authoring report, render report, and all six direct renders are kept
here as immutable negative evidence. Attempt 2 must keep the accepted anatomy as
the dominant silhouette, use fewer fitted curved construction pieces, retain
visible joint and limb transitions, reduce helmet/shoulder/boot volume, and
separate rifle-design review from any unsupported final-contact claim.

No G6 or visual acceptance claim was made for this attempt.
