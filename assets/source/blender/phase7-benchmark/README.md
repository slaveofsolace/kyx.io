# Phase 7 tactical mannequin benchmark

Status: **benchmark only; not runtime integrated; G6 not claimed**.

This folder contains a project-original, reproducible Blender source test for
KYX's cel-printed tactical manga direction. It is intentionally a small visual
and animation experiment rather than a hero character, production weapon,
viewmodel, complete rig, deformation proof, or asset-family kickoff.

## Contents

- `build_phase7_benchmark.py` constructs the source scene from primitives.
- `benchmark-spec.json` records the fixed scope and export preset.
- `provenance.json` records the no-third-party-art boundary.
- `output/` is generated by the Blender script and contains the `.blend`, GLB,
  three review frames, and a machine-readable report.

## Reproduce

From the repository root, with Blender 5.1.2:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.1\blender.exe' `
  --background `
  --factory-startup `
  --python 'assets/source/blender/phase7-benchmark/build_phase7_benchmark.py'
```

The script clears Blender's factory scene only. It does not read legacy art,
write to runtime/public folders, install dependencies, or modify package files.

## Review boundary

The benchmark tests a decisive silhouette, a single asymmetrical feature,
large ink/paper/accent value masses, a readable rifle axis, semantic naming,
an in-place pose transition, and deterministic camera/light/export setup.

It does **not** satisfy G6. Missing by design: authored skin deformation,
LOD0-2, first-person arms, production Auto Rifle, complete first/third-person
clip matrices, runtime shader/outline stability, texture/KTX2/meshopt pipeline,
close/mid/far and accessibility boards, 2/4/8-character profiling, glTF
Validator integration, and human art approval.
